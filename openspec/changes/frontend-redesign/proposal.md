## Why

当前调用图分析页面功能完整但体验粗糙：

1. **信息过载** — 状态栏显示过多技术细节（端口、项目哈希、路径）
2. **操作路径长** — 扫描完需要手动点「浏览类结构」才能看到结果
3. **调用链展示弱** — 纯文本列表，无法直观看到调用层级
4. **进度条虚假** — 固定百分比，不是真实进度
5. **布局浪费** — VS Code 侧边栏空间有限，当前信息密度低
6. **样式老旧** — 缺乏视觉层次，按钮多而不精

## What Changes

**只修改 `src/webview/callgraph/` 目录下的 3 个文件：**
- `App.tsx` — 完全重写 UI 组件
- `hooks/useCallGraphState.ts` — 重构状态管理
- `main.tsx` — 入口（可能微调）

**不修改其他任何文件**（bridge.ts、panel.ts、extension.ts、tools.ts、其他 webview 面板都不动）。

### 新 UI 设计

```
┌─────────────────────────────────┐
│ 调用图分析          [▶ 扫描] [↻] │ ← 简洁头部，只有扫描+刷新
├─────────────────────────────────┤
│ ● 已就绪 · 342 类 · 1,248 方法  │ ← 状态摘要
├─────────────────────────────────┤
│  🔍 搜索类或方法...              │ ← 过滤框（始终可见）
├─────────────────────────────────┤
│  ▶ com.example.controller       │ ← 类树（自动展开）
│     getUserById()               │
│       ├─ ↑ UserService.findById │   内联显示上下游
│       └─ ↓ UserMapper.select    │
│     createUser()                │
│       └─ ↓ ...                  │
│  ▶ com.example.service          │
│  ...                            │
└─────────────────────────────────┘
```

### 关键改动

| 改动 | 当前 | 新版 |
|------|------|------|
| 头部 | 状态点 + 标题 + Badge | 标题 + 扫描/刷新按钮 |
| 状态 | BadgeBar（4-5项） | 一行文字摘要 |
| 进度条 | 假的固定百分比 | 文字状态（无进度条） |
| 类树 | Tab 切换，需手动点浏览 | 扫描完自动显示 |
| 调用链 | 弹窗式，Tab 切换 | 内联展开，类树中直接看上下游 |
| 快速查询 | 独立区域 | 全局搜索框 |
| 日志 | 编辑器模式独有 | 移除（不影响功能） |
| Tab | 类树/追溯 两个 Tab | 无 Tab，统一视图 |
