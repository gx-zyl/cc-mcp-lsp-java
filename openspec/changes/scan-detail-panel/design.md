## 设计

扫描进度详情通过轮询返回，webview 右侧展示。

### 数据结构

```
query_scan_status 返回:
{
  "status": "running",
  "fileCount": 1,         // 已处理数
  "elapsedMs": 5230,
  "currentFile": "HdrHistogram-2.2.2.jar"  // 新增
}
```

### UI

```
┌─────────────────────┬──────────────────┐
│ 类树 (主体)          │ 扫描详情 (右侧)    │
│                     │                  │
│                     │ 扫描中 1/3 文件    │
│                     │ 已用时 5秒         │
│                     │ 当前: xxx.jar     │
│                     │ 已完成:           │
│                     │  ✓ HdrHistogram  │
│                     │  ⟳ HikariCP      │
│                     │  ☐ ST4           │
└─────────────────────┴──────────────────┘
```

右侧面板只在扫描期间显示，扫描完成后自动收起。
